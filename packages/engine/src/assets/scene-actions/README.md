# Action bar icons

The action bar uses the approved Life-sim direction: chunky silhouettes, matte
colour and two or three broad cel-shaded planes. The original Build, Walk and
Night concepts use a hammer, footprints and a crescent. Other actions follow the
same visual language with one recognisable object per action.

These are authored SVG assets on a transparent 64 × 64 canvas. Keep the outer
silhouette inside the canvas, leave room around each object and check the icon
in the 44 px mobile button as well as the 64 px desktop button. There are no
gradients, filters, embedded bitmaps, external resources or heavy outlines.

Use warm gold (`#ffd166`, `#dba33d`), sage (`#92ae6c`, `#66864b`), powder blue
(`#91b7d0`, `#5d89a8`) and cream (`#edf0df`, `#adc3c8`) as the main colour pairs.
Light faces sit above and to the left; darker faces sit below and to the right.
Avoid adding scenery, miniature houses, platforms or decorative detail.

The main dock, grouped menus and shortcut editor load these same assets. Room
photos, device previews and optional Walk tools keep their own representations.
